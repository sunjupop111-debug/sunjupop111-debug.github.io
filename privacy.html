  • 전자책 전달: 구매자가 주문 옵션에 입력한 수령 이메일을 다운로드 안내, 발송 오류 확인과 복구에 이용합니다. 구매자별 PDF에는 수령 이메일과 상품주문번호를 워터마크로 표시하는 구조입니다.
  • 중복 방지와 접근 관리: 주문 처리 상태, 파일 발급, 이메일 발송 접수 결과, 다운로드 만료와 잠금·철회 기록을 관리합니다. 발송 기록에는 이메일 주소와 메시지 식별정보가 포함될 수 있습니다.
  • 문의 처리: 이용자가 문의 과정에서 제공한 연락처와 내용을 해당 문의 확인에 이용합니다.

네이버 주문 응답의 실제 제공 범위는 API에 따라 달라질 수 있습니다. 이 홈페이지에서 카드번호·은행 비밀번호 등 결제 인증정보를 입력받지 않습니다.

3. Google 서비스와 외부 처리 경로

Google 계정 연결은 운영자의 판매용 계정에 적용됩니다. 구매자가 Google 계정을 연결하는 서비스는 아닙니다.

  • 네이버 스마트스토어와 네이버 API: 주문 정보 및 결제·취소·반품 상태 확인
  • Make: 서버와 네이버 API 사이의 요청·응답 중계
  • Google Cloud Storage와 Cloud Run: 전자책 원본 보관, 구매자별 파일 가공과 다운로드 중계
  • Firestore: 주문 장부, 중복 처리 방지, 발송 결과와 다운로드 접근 상태 관리
  • Google Drive: 판매자 비공개 공간의 고객별 전달 파일 보관
  • Gmail과 Apps Script: 주문 확인 신호 처리와 다운로드 안내 이메일 발송. 현재 신호 감지 코드는 메일 식별자를 사용하며 신호 메일 본문을 서버로 전달하지 않는 방식입니다.

외부 서비스별 처리 국가·보관 위치·보관 조건과 위탁·국외이전 세부 사항은 아직 모두 확정되지 않았습니다. 확인되지 않은 국가나 보관기간을 기재하지 않으며, 이 안내를 해당 세부 고지가 완료됐다는 의미로 사용하지 않습니다. 고객 정보와 인증 비밀값은 이 공개 홈페이지에 게시하지 않습니다.

4. 법령에 따른 거래기록 보존

  • 계약 또는 청약철회 등에 관한 기록: 5년
  • 대금결제 및 재화 등의 공급에 관한 기록: 5년

위 기간은 법에서 정한 해당 거래기록의 기준입니다. 모든 이메일, 전체 주문 응답 또는 구매자별 PDF·ZIP을 일괄 5년 보관한다는 뜻이 아닙니다. 실제 보존 대상과 범위는 해당 기록의 성격에 따라 구분해야 합니다.
